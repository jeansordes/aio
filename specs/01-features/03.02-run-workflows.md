# Run Workflows

User can run declarative workflows.

Main paths:
- `aio run`
- `aio run <workflow>`
- `aio observe` (tail the latest run’s `conversation.log` or `events.jsonl`)

Each run writes logs under `.aio/runs/`; provider output streams to the terminal by default (`--quiet` for milestones only).

Workflow states execute roles and transition until final state.
