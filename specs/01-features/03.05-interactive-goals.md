# Interactive Goals

Bare `aio` in a terminal starts or resumes one foreground goal session in the
current directory. Users describe the intended outcome and observable success
criteria, select an available harness, and follow the loop from the same terminal.
Goal mode needs neither `aio init` nor a workflow file.

The session belongs to the project. Closing the interface stops execution and
preserves the checkpoint for the next launch. Non-interactive invocations and
explicit help flags show the CLI help.
