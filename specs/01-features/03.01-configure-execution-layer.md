# Configure Execution Layer

User can configure roles and providers separately.

Providers describe how to run external AI tools through `.aio/providers.yaml`.
Roles describe agent behavior and context.

Both are project-local and replaceable.

`aio init` / `aio setup` probes known provider CLIs on `PATH` before creating
`.aio/`, lists what was found, and—when multiple CLIs respond—asks which provider
should be default for roles and workflows (non-interactive runs pick the first
detected unless `AIO_DEFAULT_PROVIDER` matches). If none are found, init fails
and explains how to install a supported CLI or configure `custom` in
`.aio/providers.yaml` once a CLI exists.

Provider output is runtime log data. Project files are the shared memory between
agents.
