# Govern Long Running Execution

User can bound and monitor long-running workflows.

Main paths:
- track token and loop usage
- compact or hand off before context saturation
- stop workflows before runaway execution burns subscription budget
- receive notifications when attention is required
- watch a real-time action and message feed

Exact accounting and limits can evolve.
The system should support context-window percentage thresholds, absolute token
budgets, loop caps for cyclic workflow regions, and project-level user caps.
