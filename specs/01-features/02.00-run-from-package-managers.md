# Run From Package Managers

User can run app from package manager command.

Main paths:
- `npx @jeansordes/aio`
- `bunx @jeansordes/aio`

Global install can also run app.

Bare `aio` starts the Goal/workflow menu in a terminal. When stdin or stdout is not a
terminal, bare `aio` prints the same man-style help as `help`, `-h`, and `--help`.
