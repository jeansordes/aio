# Run From Package Managers

User can run app from package manager command.

Main paths:
- `npx @jeansordes/aio`
- `bunx @jeansordes/aio`

Global install can also run app.

With no subcommand, or with `help`, `-h`, or `--help` first, the same man-style
help text is printed so users can discover subcommands without a separate
manual page.
