# Project Orchestration Setup

User can create and update project-local orchestration config.

Main paths:
- `aio init`
- `aio setup`

Setup creates `.aio/` without owning project docs, tasks, or specs. Init refuses
when no supported local provider CLI is available (see `03.01.03`).

Setup can suggest a project knowledge structure.

Suggested structure can match this repo:
- `specs/`
- `specs/roadmap.csv`
