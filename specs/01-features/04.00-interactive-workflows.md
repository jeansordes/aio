# Interactive Workflows

One version 2 runtime executes actions, routes, scripts and ends. Goal builds an
action/validation/end workflow. Global model profiles contain ordered CLI/model
choices; recognized availability failures can fall back with visible diagnostics.
The terminal offers keyboard menus, criteria/profile editing, numbered graph
inspection, pause, guidance and resume. Selected and running nodes are independent.
Quitting stops the running process group and restores the terminal. Scripts execute
commands and arguments without an implicit shell. Old sessions are archived when
replaced, never migrated. Global notifications retain bounded, nonblocking delivery.
