# Agent Workflows

Version 2 workflows separate agent actions, routing decisions, scripts and ends.
The Goal entry creates a simplified workflow: action, criterion-based routing,
and end, with a correction loop. Actions perform work; routes assess and decide.
Global named model profiles select ordered CLI harness/model pairs. Definitions
and resumable execution history stay in the project. Execution is foreground,
observable and bounded. No compatibility engine or automatic migration is provided.
Old project data is preserved. Machine-wide notification webhooks apply globally.
