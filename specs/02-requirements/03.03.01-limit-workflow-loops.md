# Limit Workflow Loops

Workflows can cap repeated execution.

The user can set maximum loop counts globally and for specific workflow
regions. The runner stops or asks for confirmation when a loop limit is reached.

This prevents accidental infinite loops and protects subscription or API usage.

Open design:
- global max steps per workflow run
- max visits per state
- max cycles through named loop regions
- override or resume controls when the user explicitly approves more work
