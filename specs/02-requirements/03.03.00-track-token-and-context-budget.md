# Track Token And Context Budget

Workflows track token usage and context-window pressure.

The user can configure usage limits before or during a run.
The runner can warn or stop before context saturation.

Open design:
- provider-reported token counts when available
- estimated token counts when provider accounting is unavailable
- context-window percentage thresholds
- absolute per-run token budgets
- per-project or per-user budget caps

When a threshold is reached, the workflow can compact state or hand off to a
new session with enough context to continue.
