# Scope Provider To Project Root

Providers must not inherit parent-repo agent instructions or escape the project
directory without an explicit operator choice.

Three layers:

1. **CLI isolation flags** — `providers.yaml` may define `isolationArgs` (same
   templating as `args`, including `{{project_root}}`). Cursor uses
   `--workspace` and `--sandbox enabled`. The template expands `{{isolation_args}}`
   in `args` unless `aio run` is started with `--allow-edits-outside-dir`.

2. **Git and instruction boundaries** — Child processes get
   `GIT_CEILING_DIRECTORIES` set to the project root so git-aware tools do not
   discover an enclosing repository. When the project lives inside another git
   repo or any ancestor directory contains `AGENTS.md`, `aio init` writes an
   empty `AGENTS.md` at the project root if one is missing (never overwriting),
   so agent CLIs typically stop loading instructions from parents.

3. **Opt-out** — `--allow-edits-outside-dir` disables `{{isolation_args}}`
   expansion and prints a warning; operators add equivalent flags per provider
   when their CLI supports scoping.
