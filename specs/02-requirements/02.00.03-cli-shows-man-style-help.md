# CLI shows man-style help

Invocations with no subcommand, or with `help`, `-h`, or `--help` as the first
argument, print the same man-style help text to stdout: sectioned headings
(`NAME`, `SYNOPSIS`, `DESCRIPTION`, `COMMANDS`, `EXAMPLES`, `VERSION`) and the
package version. This replaces any placeholder that claims the tool is not yet
implemented when orchestration commands already exist.

The synopsis and command list document orchestration subcommands (`init`, `setup`,
`run`, `observe`, `update`) and any standard flags described there.

Tests assert the equivalence of bare `aio`, `aio help`, `aio -h`, and `aio --help`.
Help text includes `aio observe` alongside other user commands.
