# Interactive ASCII View

Bare aio in a terminal offers resume, a standalone Goal or a project YAML workflow.
First use selects and saves an available global default harness. Goal creation
collects the objective and one or more success criteria. Validate all assigned
harnesses before starting a new session; keep existing saved work if setup fails.
The view shows node identifiers and types, active/paused state, reference arrows
for branches and cycles, and recent output. Wrap to terminal width; if the graph
exceeds the screen, show the active region with an explicit line-range indicator.
Resize updates the live view. Full events and output stay in session logs.
p+Enter pauses after the invocation. q+Enter, Ctrl+C, SIGTERM or terminal closure
stop the harness. Pauses accept guidance and resume, or quit. Restore the terminal
on exit. A completed workflow displays criterion evidence reported by its agents.
