# Keyboard Menus And Numbered Workflow Inspection

Bare aio in a terminal offers Workflow and Goal first, then a visual separator,
Resume when a compatible session exists, Settings, Version, Help, Update and Quit.
Use arrow keys and Enter, Esc to return. Missing configuration, missing workflows
and incompatible sessions explain recovery without making the main menu unusable.

Goal collects an objective and at least one criterion using explicit Add, Edit,
Delete and Finish actions. Text entry never interprets q or other menu shortcuts.
First setup offers low, mid, high with explicit CLI/model identifiers supplied by
the user. Settings can create, rename, delete profiles and edit/reorder their entries.
Profile names are referenced by workflows; renames do not rewrite project files.
Before launch, show every node and its profile, allow session-only profile changes,
and require explicit Launch. Snapshot resolved configuration before replacing work.

The native Node terminal view displays numbered nodes in snapshot order and all
outgoing numbered edges, including cycles. An animated active marker and independent
selection marker distinguish execution from inspection. Arrow keys select nodes;
f returns to the running node; PgUp/PgDn scroll details. Only selected-node details
and output are displayed. Include its name, prompt or criteria, routes, script
command, selected profile and requested CLI/model. Global fallback notices stay
visible even while inspecting another node. Full logs stay in the session directory.

Adapt to terminal width and height, scroll long menus and details, and redraw on
resize. Animate only on TTY. p pauses between invocations; q, Ctrl+C, SIGTERM and
terminal closure stop the process group. Restore raw mode, cursor and screen on exit.
Paused sessions allow guidance and resume, return to menu or quit. Completion shows
the results and criterion evidence before returning to the menu.
