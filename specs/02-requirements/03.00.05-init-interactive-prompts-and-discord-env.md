# Init Interactive Prompts And Discord Env

Interactive `aio init` / `aio setup` uses arrow-key prompts for tracking choices
and default provider selection.

Optional Discord notifications: the user may opt in to store `DISCORD_WEBHOOK_URL`
and optional `DISCORD_MENTION_USER_ID` in `.aio/.env`. That file is gitignored
via `.aio/.gitignore` from the default template so secrets are not committed.

Non-interactive init is unchanged for CI and scripts (no inquirer; no Discord prompt).
