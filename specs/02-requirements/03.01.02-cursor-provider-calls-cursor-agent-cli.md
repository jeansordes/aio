# Cursor Provider Calls Cursor Agent CLI

The generated `providers/cursor.sh` must invoke the [Cursor Agent CLI](https://cursor.com/docs/cli) (`cursor-agent` on `PATH`).

- Read the standard JSON request on stdin (workflow, role, `instructions`, `contextFiles`, `previousOutputs`, `projectKnowledge` including `trackingFile`).
- Build a text prompt and run `cursor-agent` in non-interactive print mode, for example: `-p`, `--force`, `--trust`, and `--output-format json` so scripts can parse stdout. Support optional `--model` when the role’s model is not `default`.
- Require `CURSOR_API_KEY` (or the CLI’s normal auth) in the user environment.

The wrapper writes the agent’s stdout to the process stdout. Other generated providers may remain not-configured placeholders.
