# Update Command Applies Global Update

`aio update` applies newer package versions immediately for persistent global
npm, pnpm, and Bun installs that aio can detect (same path rules as startup).

The command reuses the same installer mapping as the startup update path.
It does not ask for confirmation because the user explicitly requested an
update.

After a successful update, it prints relaunch instructions.
For npx, bunx, local, or unknown invocations, it does not mutate the environment
automatically and prints manual install commands instead. On a normal `aio`
invocation, when a newer version exists and self-update is not available, a
one-line notice may be printed to stderr; `AIO_NO_UPDATE_CHECK=1` disables
registry checks and such notices.
