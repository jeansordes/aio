# Global Harnesses

Read only XDG_CONFIG_HOME/aio/config.yaml or ~/.config/aio/config.yaml.
Define harnesses, defaultHarness and optional defaultModel globally. Cursor and
Codex are built in. Custom commands accept a prompt argument or stdin.
Relative command paths resolve from the global config directory.
Nodes can override harness and model. Reject unknown or unavailable selections;
never silently substitute another harness. Save the initial selection globally.
Authentication belongs to the harness. Project provider files are not consulted.
