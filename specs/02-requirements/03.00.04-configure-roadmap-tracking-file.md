# Configure Roadmap Tracking File

During `aio init` / `aio setup`, the user chooses the project file used for task and roadmap tracking.

- Non-interactive runs auto-detect a default from common paths in order: `specs/roadmap.csv`, `TASKS.md`, `ROADMAP.md`.
- Interactive runs show a short guided prompt: **Enter** accepts the default (use the detected file when one exists; otherwise scaffold `specs/` + `specs/roadmap.csv` and use that path). You can still type a custom path, **`s`** to scaffold the specs tree explicitly, or **`n`** for no tracking file.

The chosen value is written to `.aio/config.yaml` under `tracking.file` (or
`null`). Workflow runs include that path in provider prompts when the provider
configuration requests `tracking_file`.
