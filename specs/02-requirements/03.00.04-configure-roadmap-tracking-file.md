# Configure Roadmap Tracking File

During `aio init` / `aio setup`, the user chooses the project file used for task and roadmap tracking.

- Non-interactive runs auto-detect a default from common paths in order: `specs/roadmap.csv`, `TASKS.md`, `ROADMAP.md`.
- Interactive runs prompt: accept the detected default, type a custom path, choose `s` to scaffold `specs/roadmap.csv` (and the rest of the optional specs tree), or `n` for no file.

The chosen value is written to `.aio/config.yaml` under `tracking.file` (or `null`). Workflow runs pass that path to provider wrappers in `request.projectKnowledge.trackingFile`.
