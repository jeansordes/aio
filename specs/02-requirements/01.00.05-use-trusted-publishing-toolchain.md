# Use Trusted Publishing Toolchain

Release workflow must use a Node and npm version that supports npm trusted
publishing through GitHub OIDC.

Use Node `22.14.0` or newer.

Use npm `11.5.1` or newer.

The workflow may be manually dispatched for an existing release tag when npm
trusted publishing or release infrastructure was fixed after the tag was pushed.

Package metadata must include the GitHub repository URL expected by npm
provenance verification.
