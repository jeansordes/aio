# Replace Legacy Orchestration

The public commands remain bare aio, help, version and update. Ship only version 2
workflow execution. Remove goal/maxTurns, direct per-node harness/model selection,
global defaultHarness/defaultModel and per-harness implicit models. CLI harnesses
resolve explicit profile entries; no legacy fallback path or automatic conversion.
Old project data is preserved and archived when starting a new session.

The README, help, specs and roadmap describe actions, independent criterion routing,
scripts, ordered model profiles, keyboard settings, numbered node inspection and
snapshot resume. Include valid implementation/validation and script action/routing
examples in the npm package. Document literal CLI identifiers, recognized failure
boundaries, partial-work preservation and the limits of agent-reported evidence.
Keep notification, distribution and update behavior. Commit by requirement and push
the branch. Version bumps, tags and publication remain a separate operation.
