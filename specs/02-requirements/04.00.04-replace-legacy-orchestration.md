# Replace Legacy Orchestration

The public surface is bare aio, help, version and update. Remove init, setup,
run and observe commands; legacy role files, condition expressions, scaffolding,
Discord integration and unused execution code. Keep update and distribution
behavior and release tooling. No compatibility layer or automatic migration.
Do not delete project data created by older versions.

Current specs, roadmap and README describe only the unified runtime. Historical
behavior is documented in the changelog. Include a valid example YAML workflow
in the npm package. New features are committed and pushed; a release is separate.
