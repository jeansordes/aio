# Per-State AI Summary

A workflow state may opt into a follow-up provider call that asks the same
role’s provider to summarize the step.

YAML shape:

- `summary: true` — enable with default summary instructions
- `summary.enabled: true` with optional `summary.prompt: "..."` — custom wording

The summary runs only after the main provider call succeeds (`status: ok`).
The summary text is stored on the step output (`summary` field) and is included
in Discord step notifications when configured.
