# Per-State AI Summary

Post-step summarization is a **normal workflow state**, not a special YAML flag.

Use an extra state after the work you want summarized (see the default template’s
`summarize` role and state after `publish`). That role’s instructions tell the
agent to read `.aio/runs/latest` and the matching `conversation.log`, then
produce a short summary. Roles can include `run_dir` in `prompt.include` so the
prompt lists the current `runId` and absolute `runDir` for the active loop.

The historical `summary: true` / `summary.enabled` keys on a state are removed:
they are ignored if still present in old workflows. Prefer an explicit
`summarize` (or similarly named) state and role.
