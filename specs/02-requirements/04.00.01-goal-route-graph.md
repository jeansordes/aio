# Goal Route Graph

A YAML workflow has name, initial, nodes and optional maxInvocations (default 100).
A goal node owns objective, nonempty criteria, optional instructions and maxTurns
(default 10), and next. A route node owns instructions and routes: each has to and
description. An end node has no agent invocation. Agent nodes may override harness
and model directly. A standalone Goal is an in-memory goal/end graph.
Load project workflows from .aio/workflows/*.yaml or *.yml. Reject unknown fields,
missing references, invalid limits, ambiguous duplicate routes and reachable nodes
with no path to an end. Cycles with an exit are supported. No roles or technical
condition expressions are part of this format.
