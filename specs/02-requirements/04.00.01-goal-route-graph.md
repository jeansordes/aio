# Version 2 Workflow Graph

Require version: 2, name, initial, nodes, optional maxInvocations (default 100).
Action nodes have prompt, modelProfile (default mid), next, optional name.
Route nodes have prompt, modelProfile (default low), routes with to/description,
optional nonempty criteria and name. End nodes have type and optional name.
Script nodes have command, args, optional timeoutMs (default 600000), optional name,
and exactly one of next or routes. Timeouts must be positive supported timer values.
Agent nodes cannot select a concrete harness/model or carry legacy goal fields.

Goal creates action/validation/end with a correction loop. Its action receives the
objective and criteria as prompt context; validation owns the criteria and verdict.
Project definitions live in .aio/workflows/*.yaml or *.yml. Reject old formats,
unknown fields, absent references, duplicate routes, empty criteria and reachable
nodes without a path to end. Persist node order for stable displayed numbering.
